# Public landing page

This directory is the Astro static marketing site for `https://about.bi.runlumi.app`,
not the authenticated React BI application in `apps/web` at `https://bi.runlumi.app`.
Root AGENTS.md and DESIGN.md remain authoritative; their shadcn/Tailwind component
rules govern the authenticated React application only — this static Astro site stays
plain HTML/CSS with no React, Tailwind or shadcn runtime. Do not couple this build to the
installation operations, installation database, application session, or a Cloudflare API token.

Preserve these outcomes:
- An owner understands the money, stock and operations questions, then can open
  an email conversation about a pilot. No fake form, registration or success state.
- All commerce examples are synthetic and labelled. Roadmap connectors and Ask
  Lumi must not become claims of production capability. Read the root README
  before changing product copy. Do not invent testimonials, logos, savings or prices.
- Core content, evidence details, navigation and contact work without JavaScript.
  Enhancements use real keyboard-operable tabs, focus states and reduced motion.
- Warm paper, exact palette, Geist, canonical folded-L geometry and editorial
  whitespace come from DESIGN.md. No decorative AI imagery or dark theme.

`src/data/site.ts` owns public identity and reviewed FAQ answers. Astro config,
canonical/social metadata, JSON-LD, robots, sitemap and llms.txt must agree on the
landing origin. Render FAQ markup from the same answers users can read, only on
the homepage. Author is the Lumi BI publishing organization, not an invented
person or credential. Keep review dates editorial, not regenerated by a build.
`src/lib/geo.ts` owns escaped JSON-LD and the public llms summary. The only inline
script allowed is validated `application/ld+json` data. Never relax CSP with
`unsafe-inline` or `unsafe-eval` for SEO. See `GEO.md` for evidence and boundaries.

`src/data/demo.ts` owns synthetic calculations. Check sums and denominators before
changing a chart. Null, missing, estimated, contribution, profit and actual cash
are different concepts. UI examples are not API integration tests.

Before shipping run `npm ci --ignore-scripts`, `npm run check`, `npm run build`,
and `npm run test:e2e` with the pinned browser installed. Use Node 24.21.0 from
this directory's `.nvmrc`. Inspect desktop/mobile screenshots and retain the
actual commit/run identity. A passing local preview is not proof of Pages
headers, DNS, email delivery or production accessibility.

Keep the dependency graph locked. No framework hydration, analytics, storage,
external fonts, secrets or API calls without an explicit product requirement and
review of privacy, CSP and performance. Publish font notices in every build.
